# ResetTorqueRange

With the method `ResetTorqueRange`, you reset the upper and lower torque or force limits previously configured by [`SetTorqueRange`](SetTorqueRange.md).

## Underlying Instruction

- Native `MC_TorqueRange` executed with `Enable := FALSE`.

## Effects

- Disables the torque range limiting function block on the drive.

## Parameters

This method does not take any input parameters and has no return value.
