# ResetTorqueAdditive

With the method `ResetTorqueAdditive`, you reset an additive torque or force previously set by [`SetTorqueAdditive`](SetTorqueAdditive.md).

## Underlying Instruction

- Native `MC_TorqueAdditive` executed with `Enable := FALSE`.

## Effects

- Sets the additive torque/force transferred to the drive to zero and deactivates the function block.

## Parameters

This method does not take any input parameters and has no return value.
